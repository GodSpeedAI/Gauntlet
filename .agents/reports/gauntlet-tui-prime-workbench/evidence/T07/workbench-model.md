# T07 Evidence — React-Free Workbench Model & Immutable Snapshot Fan-Out

Date: 2026-09-08
Task: T07
Proof Level: P2
Scope: Host-level React-free Workbench Model, immutable snapshot distribution, multi-projection non-destructive fan-out (Work, Chat, Trace), and separation of Chat from causal Trace history.

## Settled Requirements

- **REQ-DATA-001**: React-free Workbench Model in the Bun host publishing immutable snapshots to presentation code.
- **REQ-DATA-005**: Chat and Trace are separate projections over durable execution/session history; Chat is NOT canonical input for Trace (Attack 1).
- **REQ-DATA-006**: One authoritative source event fans out to multiple projections non-destructively; no view can independently consume or acknowledge an event in a way that starves another view (Attack 2).
- **REQ-TUI-001**: OpenTUI and React presentation code consume immutable snapshots and interaction callbacks; presentation components do not own Gauntlet/Prime business state.
- **REQ-GOAL-005**: Multi-surface projection consistency across views.

## Implementation Details

1. **`workbench/src/workbench-model.ts`**:
   - `WorkbenchModel`: Manages generation lifecycle, event fan-out, and immutable snapshot publishing.
   - `subscribe(listener)`: Subscribes presentation layers to immutable snapshots with immediate initial emission and clean unsubscribe.
   - `applyEvent(frame)`: Directs each authoritative frame to:
     1. SQLite projection store (Work, Evidence, Sessions, Cursors)
     2. Trace projection reducer (`trace_records` array)
     3. Chat projection reducer (`chat_messages` array, if enabled)
   - `getSnapshot()`: Returns an immutable `FullWorkbenchSnapshot` with frozen arrays for trace and chat records.
   - `selectFocus` & `selectHorizon`: Host-level interaction callbacks updating the snapshot.

2. **`workbench/src/workbench-model.test.ts`**:
   - Verifies snapshot publishing, subscription lifecycle, snapshot immutability, and interaction callbacks.

3. **`workbench/src/projection-fanout.test.ts`**:
   - Verifies multi-projection fan-out and both teeth attacks.

## Teeth Falsification & Verification

### Attack 1: Remove Chat projection entirely and reconstruct Trace for the same run (REQ-DATA-005)
- **Attack description**: Run an identical authoritative event stream through two models: one with Chat enabled (`chatEnabled: true`) and one with Chat completely disabled (`chatEnabled: false`).
- **Defense outcome**: The Trace projection generated by both models is 100% identical and bit-equivalent (`expect(traceWithoutChat).toEqual(traceWithChat)`). Chat contains 0 messages in the disabled model, yet Trace contains all causal records with full fidelity. Proves Chat is non-canonical for Trace.
- **Test**: `src/projection-fanout.test.ts` ("Attack 1 (REQ-DATA-005): Chat is not the canonical source of Trace; disabling Chat leaves Trace identical").
- **Result**: **PASS**.

### Attack 2: Work and Trace both depend on one canonical event without starvation (REQ-DATA-006)
- **Attack description**: Deliver a single authoritative event (`unit_updated`) to the model.
- **Defense outcome**: Both Work (unit updated in SQLite projection) and Trace (audit causal trace record) receive and reflect the update in the subsequent published snapshot. Neither view starves or consumes the event away from the other.
- **Test**: `src/projection-fanout.test.ts` ("Attack 2 (REQ-DATA-006): Work and Trace both depend on one canonical event without starvation").
- **Result**: **PASS**.
