NOT CONFIRM

1. Trusted dispatch remains forgeable by raw/recomputed input. `build_envelope` only recomputes the caller-supplied `ObservationBundleDoc` digest (`crates/gauntlet-app/src/compare/envelope.rs:190`); `ObservationBundleDoc::new` is public (`crates/gauntlet-app/src/observation/bundle.rs:583`). A caller can construct a bundle containing smuggled builder material in an allowed text field (for example a facet command), recompute its digest, and pass it. The P2 check rejects only deny-listed JSON *field names*, and the source explicitly concedes that caller-supplied projection provenance is a separate gap (`envelope.rs:346`). Likewise, public `FrozenReferenceProjection::load` and `TrustedComparisonContext::from_frozen_projection` (`crates/gauntlet-ports/src/comparator.rs:694,772`) bind an envelope merely to a caller-provided `ReferenceVersion`, not to the durable run's frozen reference before dispatch. This does not meet Core §13.2's runtime-built, fresh-context envelope requirement.

2. Durable acceptance and run/invocation/reference binding are bypassable. `review` publicly returns a consequential `ReviewOutcome`/`ComparisonRecordDoc` (`crates/gauntlet-app/src/compare/review.rs:205,275,586`) with no `MandatoryComparisonAcceptance`, evidence pin, or state-store admission. `DiffComparator::comparison_document` and `compare` directly emit records (`crates/adapters/gauntlet-adapter-compare-diff/src/lib.rs:112`) without a role invocation, durable evidence, or `StateStore::accept_comparison`. Thus a caller can use the current review/deterministic-adapter paths while avoiding the mandatory acceptance boundary. That conflicts with Core §13.2 (digest on both RoleInvocation and ComparisonRecord) and §18.1 (comparisons and role invocations are minimum durable records).

3. The declared deadline is not actually enforced during model fan-in. `PendingModelComparison::collect` accepts `deadline` but calls `drive_to_terminal_with` without it; that function polls a fixed `PROBE_CEILING` and never checks the deadline (`crates/adapters/gauntlet-adapter-compare-model/src/lib.rs:299-301,373`). Consequently an already-expired deadline can still make 24 polls, rather than satisfying Core §10.3 rule 5's “no result by deadline” timeout/cancel requirement. The lease/cancellation tests cover scripted forever-running and cancellation-refusal cleanup, but do not repair this deadline bypass.

4. High-assurance adversarialness is not enforced at the review boundary. `AdversarialComparatorSource` is a public, unconstrained trait (`crates/gauntlet-ports/src/comparator.rs:908`); `review` only requires `Some(adversarial)` and trusts its returned comparator. Although `ModelAdversarialSource` constructs the right prompt, another source can satisfy the trait with an ordinary comparator. Therefore `high_assurance` is not structurally guaranteed to include the Core §13.3 adversarial pass.
