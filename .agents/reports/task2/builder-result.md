## Decisions

1. **`[lints] workspace = true` block form, not the dotted key.** On this cargo (1.92.0), `lints.workspace = true` inline under `[package]` is silently ignored ("unused manifest key: package.lints" and no rustc lint flags). The block form inherits correctly — verified by teeth: an `unsafe` block in gauntlet-domain failed to compile with the forbid applied, then reverted.
2. **Repo root is `CARGO_MANIFEST_DIR/../..`.** The task text's `/../../..` overshoots the repo root by one level (`CARGO_MANIFEST_DIR` is already `<repo>/crates/gauntlet-arch-tests`). Documented in `walk.rs`.
3. **Dependency scanning covers target-scoped sections and `path`/`package` forms.** A `cfg`-scoped dependency is still a dependency; `path = "..."` entries are resolved against member directories so a rename or relative path cannot hide an internal dep. Self-tests cover both evasion forms.
4. **Unclassified workspace members fail loudly** rather than pass silently: any member that is not domain/ports/app/cli/adapter/arch-tests is itself a violation naming the crate. This enforces the orchestrator's Task 2 crate set without freezing a literal list — a later task adding an adapter crate classifies automatically via `crates/adapters/`, anything else must be classified deliberately.
5. **Anti-vacuity asserts in every repo-level test**: the walker must actually find the four core manifests and lib roots; an empty scope can never pass.
6. **Denylist on `Cargo.toml` checks dependency keys and `package = "..."` renames** in all dependency sections (incl. `[target.*]`); line numbers located by raw-text search, reported unlocated rather than wrongly located if absent. `.rs` files are scanned whole (comments and string literals included).
7. **Literal scan applies to whole `Cargo.toml` text** — "same source scope as (b)" read as the same file set, with the literal rules over the full text (a hardcoded URL in any manifest field is still hardcoded). The `crates/gauntlet-app/src/config/` whitelist is a directory (documented in `walk.rs`); `defaults.rs` (Task 5) will be its only file.
8. **`#![cfg(test)]` on gauntlet-arch-tests**: the crate is a test binary, contributes nothing to normal builds, and cannot become a production dependency surface.
9. **deny.toml adjustments forced by cargo-deny 0.20.2**: `[bans]`/`[sources]` reject the `version` key (v2 is implied there) — omitted in those two sections only; `unused-allowed-license = "warn"` so the mandated forward-looking allow list does not error on entries today's tree has not encountered yet; `private = { ignore = true }` because workspace crates are `publish = false` and deliberately carry no license field while the repo LICENSE choice is the recorded open unknown UNK-002. No license was invented.
10. **CLI declares domain+ports+app now** (its allowed set) and no adapter deps — wiring lands in later tasks. Adapters declare no deps at all until the port traits exist.
11. **Pre-existing working-tree modifications** to `AGENTS.md`, `.agents/specs/Core-spec.md` (facet rename `git`→`versioning`), and `.agents/CURRENT_STATUS.md` were present before this task and were left exactly as found — they are not this builder's output.
