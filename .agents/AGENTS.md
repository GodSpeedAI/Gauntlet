

## Guidelines for Maintaining the `.agents/` Directory
- `.agents/` should remain current and accurate, reflecting the latest state of the codebase and agent instructions.
- Keep `.agents/CURRENT_STATUS.md` current 
- Add Lessons learned during implementation work  `.agents/lessons/` 
- Ensure that all agents have clear and concise documentation in `.agents/AGENTS.md`.
- Regularly review and update the `.agents/AGENTS.md` instructions to ensure they are effective and relevant, pariticularly on run where there are many lessons learned and changes to the project architecture.
