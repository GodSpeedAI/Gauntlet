# Operator guide

The primary operator surface is the CLI (spec §20.1). This guide describes
the shipped surface and the operator's role in the loop. Per-unit
conformance truth lives in `.agents/reports/conformance.json` and
`.agents/reports/handoff.md`.

## The command surface

The committed golden snapshot `crates/gauntlet-cli/tests/cli_surface.rs`
pins the surface; its fixture `crates/gauntlet-cli/tests/cli_help.txt`
carries the exact current usage text (regenerated by a documented
procedure whenever the surface changes). The verbs:

```text
gauntlet doctor      preflight; machine-readable doctor.json; non-zero on failure
gauntlet init        scaffold config, roles, skills, policies, .env.example
gauntlet reference   digest | validate | form | freeze | show | diff | verify
gauntlet run         [--dry-run] "<intent>"
gauntlet status      runs, units by tier, in-flight invocations, budget burn
gauntlet inspect     run / iteration / invocation / unit / evidence detail
gauntlet verify      re-run verification for a unit or a whole run
gauntlet resume <run_id>
gauntlet escalations list | resolve | retry
gauntlet roles       install | verify | list
gauntlet skills      install | verify | list
gauntlet improve     propose | evaluate | baseline | promote | rollback
gauntlet export      deterministic JSONL of a run
```

`gauntlet serve` (the loopback JSON API of spec §20.2) exists behind the
`surfaces` feature flag; the default build is CLI-only.

## The operator's role in the loop

The loop runs unattended until it needs authority only an operator holds:

- **Escalation queue** (`gauntlet escalations list`) is the operator's
  actionable inbox: `irreversible` units standing on their authority gate,
  governance-routed `lead_agent` closures, validation-failure escalations,
  exhausted budgets. `resolve` and `retry` ride the same atomic commit
  sequence as automatic settlement and cannot settle a unit lacking a
  durable PASS record — the refusal is typed and honest (task 21).
- **Authority raises.** An agent may never lower a Unit's blast radius or
  authority; only the operator raises either (spec §17.1).
- **Runner selection** is the operator's standing decision (unknown
  UNK-003): the repository deliberately names no `runners.default`;
  resolve one through `$GAUNTLET_AGENT_RUNNER` and the per-role variables.
- **Live containment** is deliberate: away from the conservative `none`
  default, configure `sandbox.backend` and let `gauntlet doctor` measure
  the backend before any above-`contained` dispatch.

## Everyday flows

```text
# preflight before anything else
gauntlet doctor

# see what a run would do without writing anything
gauntlet run --dry-run "<intent>"

# run, then supervise
gauntlet run "<intent>"
gauntlet status --run <run-id>
gauntlet inspect --run <run-id> --verifications --settlements
gauntlet escalations list

# after a crash
gauntlet resume <run-id>

# durable evidence out
gauntlet export --run <run-id>
```

Run reports (including `doctor.json`) land under `.agents/reports`.
Logs are structured `key=value` with `run_id`, `iteration_no`,
`invocation_id`, `unit_id` context fields; secrets are never printed.

## Proven vs provisional

Status categories are spec §26's six; unit-level claims defer to
`.agents/reports/conformance.json`.

- implemented_and_proven — AK-060: the CLI carries the full §20.1
  surface — the cli_surface suite executes every verb through the real
  binary against the golden help snapshot (task 20; the frozen-locator
  divergence is the recorded 2026-08-31 reference-candidates entry).
- implemented_and_proven — AK-061: the core builds and runs a full
  loop with operator surfaces limited to the CLI — the mock E2E completes
  end to end and the `surfaces` feature build stays byte-identical
  CLI-only by default (tasks 20–21; the frozen locator is the recorded
  `build/cli-only-profile` divergence).
- implemented_and_proven — AK-062: operator resolve and retry actions
  perform the same atomic commit sequence as automatic settlement and
  cannot settle a unit lacking PASS evidence — refusal parity executed
  byte-identical across the CLI and API surfaces, the positive
  earned-settlement path proven through both exactly-once
  (`crates/gauntlet-cli/tests/operator_actions_no_bypass.rs`, task 21).
