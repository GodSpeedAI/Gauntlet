The innermost kernel of Gauntlet. Enforces strict constructor invariants and houses core state machines. It has zero internal workspace dependencies and zero external framework dependencies (no SQL, no HTTP, no CLI libraries).

Autonomous agent harnesses fail when they collapse distinct epistemic concerns into a single model turn. Gauntlet enforces four fundamental separations:

Separation 1
Transform ≠ Observe
Defect in Ordinary Systems: The agent that wrote the code self-reports that tests passed, hiding unrun or failed checks.
Gauntlet Architectural Seam: Builder prose is segregated into an excluded facet. Independent Observer probes (cargo nextest, git diff) record verified facts.
Separation 2
Observe ≠ Compare
Defect in Ordinary Systems: Observation facts are conflated with subjective evaluations, leading to subjective goalposts.
Gauntlet Architectural Seam: Observers collect raw facts (exit codes, AST diffs). The Comparator (Critic) runs in fresh context against the frozen Reference to emit residuals.
Separation 3
Compare ≠ Verify
Defect in Ordinary Systems: An LLM code reviewer says "this looks good", which is accepted as proof that the feature works.
Gauntlet Architectural Seam: Critics emit residuals; only deterministic instruments evaluate claim locators to yield 3-state Outcome::PASS.
Separation 4
Execute ≠ Settle
Defect in Ordinary Systems: Process exit 0 or agent message "Done" is treated as task completion, ignoring budget or drift.
Gauntlet Architectural Seam: Settlement is an atomic commit verifying 5 preconditions: all units PASS, lockfile hash zero drift, budget within limits, fsync event log.
